# My second website (RDR2 landing page)

## Description

This project is a deeper dive into what is possible when using CSS to style a static HTML website. Building on my first HTML-only website, I wanted to explore how CSS can improve the appearance, layout, and overall user experience of a webpage.

## Features
 
Website includes:
- Single HTML page
- External hyperlinks
- External CSS stylesheet
- Custom fonts and colors
- Responsive design for different screen sizes

## Technologies Used 

I built this website using **HTML** and then styled using **CSS** 

## What I Learned

I gained more experience writing HTML and CSS, particularly how CSS selectors, specificity, and cascading rules determine which styles are applied to different elements. I also learned more about organizing a stylesheet and making a webpage display properly across different screen sizes.
